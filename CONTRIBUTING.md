# Contributing to Discipline Tracker 🚀

Thank you for considering contributing to **Discipline Tracker**! Open-source contributions from developers of all skill levels are welcomed and appreciated.

---

## 🌟 How Can You Contribute?

You can contribute in several ways:
1. **Reporting Bugs:** Found a glitch or UI bug? [Open an Issue](https://github.com/) with repro steps.
2. **Suggesting Enhancements:** Have an idea for a streak feature or AI insight? Open a Feature Request.
3. **Submitting Pull Requests (Code):**
   - Implement an open issue labeled `good first issue` or `help wanted`.
   - Add new habit categories or sound effects.
   - Refactor or write widget/unit tests.
4. **Improving Documentation:** Fix typos, improve explanations, or add setup screenshots.

---

## 🛠️ Development Setup

1. **Fork & Clone** the repository:
   ```bash
   git clone https://github.com/baadaldev/To-Do-App-For-Me.git
   cd To-Do-App-For-Me
   ```

2. **Install Dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the App:**
   ```bash
   # Run on Chrome
   flutter run -d chrome

   # Or run on connected Android/iOS device
   flutter run
   ```

4. **Verify Lints & Code Style:**
   ```bash
   flutter analyze
   flutter test
   ```

---

## 🌿 Git Workflow

1. Create a feature branch off `main`:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. Make your changes and commit with clear, descriptive commit messages:
   ```bash
   git commit -m "feat(ai-coach): add evening focus window insight"
   ```
3. Push your branch to GitHub:
   ```bash
   git push origin feature/amazing-feature
   ```
4. Open a **Pull Request (PR)** against `main`.
